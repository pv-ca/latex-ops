# Statistics in LaTeX documents

Read when a document reports data analysis: descriptive tables, tests, models, plots of data. The layout rules matter less than the first one: every number must come from the user's data or analysis output, never from estimation.

## 1. Where numbers come from

- Compute in the analysis software (R, Python, Stata, Julia, a spreadsheet) or read them from the data file inside the document (`pgfplotstable`). Do not do arithmetic in your head for anything printed.
- When the user supplies results, copy them exactly, with their precision. Rounding for display is allowed only when stated and consistent.
- Missing statistics (no CI given, no effect size) receive a visible draft marker such as `\textbf{[CONTENT: 95\% CI not supplied]}` and an entry in the delivery's pending-content list. Source comments alone do not warn a PDF reader; never invent the missing values.
- Keep the analysis reproducible: generated tables and figures go in files the `.tex` includes (`\input{tables/model.tex}`, `\includegraphics{figures/fig1.pdf}`), regenerated by a script, never pasted and edited by hand.

## 2. Reporting results

- Report the estimate, its uncertainty and the test, not only a p-value: `$t(48) = 2.31$, $p = .025$, $d = 0.65$, 95\% CI $[0.08, 1.21]$`.
- Exact p-values to two or three decimals; `p < .001` below that. APA style drops the leading zero for quantities that cannot exceed 1 (p, r, R²); other styles keep it. Follow the venue.
- Name the test and its assumptions (normality, equal variances, independence) and how they were checked.
- Effect sizes with their definition (Cohen's d, Hedges' g, η², odds ratio, R²). Confidence intervals in brackets with the level stated.
- Multiple comparisons: say which correction was used.
- Sample sizes everywhere they change: overall, per group, after exclusions, with reasons for exclusions.
- Italicise statistical symbols that are variables (*M*, *SD*, *t*, *F*, *p*, *n*) when following APA; Greek letters stay upright or italic per the math font.

## 3. Tables

- `booktabs` rules, no vertical lines; `siunitx` `S` columns align numbers on the decimal point: `S[table-format=-1.3]` (sign, integer digits, decimals).
- Headers in braces inside `S` columns: `{$M$}`. Units in the header, not in each cell.
- Standard errors or CIs under or beside the estimate consistently; significance stars only if the field expects them, with the legend in the table note.
- Regression tables: generate them. Python: `pandas` `Styler.to_latex(hrules=True, siunitx=True)`, `pyfixest`, `stargazer`. R: `modelsummary` (`output = "latex"`), `fixest::etable`, `kableExtra`. Include them with `\input`.
- Notes under a table with `threeparttable` (`tablenotes`) or a small paragraph after `\end{tabular}`.
- Long tables: `longtable` (repeats the header on each page).

## 4. Plots with pgfplots

- Read data from CSV: `\pgfplotstableread[col sep=comma]{data.csv}\data`, then `\addplot table[x=dose, y=response]{\data};`.
- Error bars: `\addplot+[error bars/.cd, y dir=both, y explicit] table[x=x, y=mean, y error=se]{\data};`.
- Box plots: `\usepgfplotslibrary{statistics}` with `boxplot` (computes from raw data) or `boxplot prepared` (from given quartiles).
- Histograms: `\addplot+[hist={bins=20}] table[y=value]{\data};`; say the bin count.
- Scatter with fit: plot the points, add the fitted line from the coefficients the analysis produced (`\addplot[domain=0:10] {1.2 + 0.8*x};`), and state the model in the caption.
- Grouped bars: `ybar`, `symbolic x coords`, `nodes near coords` only when the exact values matter.
- Very large datasets (thousands of points): render in the analysis tool to PDF (`matplotlib` with the `pgf` backend or `savefig("fig.pdf")`, `ggplot2` with `cairo_pdf`) using the document's fonts, then `\includegraphics`.
- Same rules as all figures: labelled axes with units, readable tick labels, colour plus marker or line style, captions that state the finding.

## 5. Statistical notation

- Define estimators and models in display math with every symbol explained: `y_i = \beta_0 + \beta_1 x_i + \varepsilon_i`, `\varepsilon_i \sim \mathcal{N}(0, \sigma^2)`.
- Expectation and variance as declared operators: `\DeclareMathOperator{\Var}{Var}`, `\DeclareMathOperator{\Cov}{Cov}`, `\newcommand{\E}{\mathbb{E}}`.
- Estimates with hats (`\hat\beta`), sample statistics with bars (`\bar{x}`), distributions upright or calligraphic consistently (`\mathcal{N}`, `\mathrm{Bin}(n, p)`).
- Probability: `\Pr(A \mid B)` with `\mid`.

## 6. Checklist before returning a statistical document

- Every number traces to the data, the analysis output or the user.
- Sample sizes add up across tables and text.
- The same statistic has the same value and precision everywhere it appears.
- Figures and tables agree with each other and with the text.
- Assumptions, corrections and exclusions are stated.
