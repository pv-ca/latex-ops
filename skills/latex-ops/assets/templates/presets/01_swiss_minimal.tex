\section{Primary hierarchy}
The page should feel organized before it feels decorated. Use position, whitespace,
scale, and weight before introducing rules, boxes, or color.

\subsection{Example component}
\begin{keypoint}
\textbf{Key point.} A semantic callout should exist because the content requires a distinct
reading mode, not because the page needs decoration.
\end{keypoint}
