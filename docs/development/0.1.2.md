## Verification commands

```sh
python3 -m unittest discover -s tests -v
LATEX_OPS_INTEGRATION=1 python3 -m unittest discover -s tests -v
python3 tests/build_templates.py --workdir /tmp/latex-ops-012-templates --gallery /tmp/latex-ops-012-gallery
```

The first command requires no TeX and reports real-build tests as skipped. The second requires its declared TeX tools: missing tools fail instead of silently skipping. CI runs real-build checks explicitly on Linux and Windows with TeX Live. MiKTeX and macOS native testing remain future work, not 0.1.2 coverage. Rendered gallery files are not evidence of visual inspection.
